# License audit

Repository-authored source is proprietary and marked `UNLICENSED` in package metadata. Dependency versions and declared metadata are in the CycloneDX SBOM. This is not legal advice and does not declare every transitive dependency acquisition-safe.

Release gate: run a license-scanning tool against the lockfile and generated SBOM, classify permissive, weak-copyleft, strong-copyleft, proprietary, and unknown results, and have counsel review unresolved entries before a transaction or production release.
