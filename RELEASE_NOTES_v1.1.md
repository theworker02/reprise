# Reprise v1.1.0-rc.1 release notes

## New

- Reprise Signal: signed, dimension-by-dimension recoverability posture for an integrity-valid checkpoint.
- Durable local checkpoint repository with atomic persistence.
- Neon Management API adapter for documented branch lifecycle operations, backed by mocked provider contract tests.
- A polished static public site with an interactive deterministic recovery scenario.
- GitHub Actions validation and Pages deployment workflows.
- CycloneDX SBOM generation and expanded acquisition diligence documents.

## Release status

`1.1.0-rc.1` is not approved for general production use. It is a technically validated release candidate. The remaining gates are listed in [docs/V1_LIMITATIONS.md](docs/V1_LIMITATIONS.md) and [acquisition/RISK_REGISTER.md](acquisition/RISK_REGISTER.md).
